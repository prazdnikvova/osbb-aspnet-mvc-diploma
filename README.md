# ОСББ — вебзастосунок для об'єднання співвласників (диплом, 2018)

Бакалаврський дипломний проєкт: вебзастосунок для ОСББ. Облік квартир і власників (площа, вартість, субсидія, пільги) та мешканців, сторінка «Про ОСББ», контакти правління й аварійних служб, посилання на комунальні служби, вхід і реєстрація користувачів.

**Технології:** ASP.NET MVC 5.2, .NET Framework 4.6.1, Entity Framework 6.2, ASP.NET Identity 2.2, Razor, Bootstrap 3, SQL Server LocalDB. У першій версії проєкту — впровадження залежностей через Unity.

## Структура

- `OSBB-N.sln`, `OSBB-N/` — фінальна версія (з 05.06.2018):
  - `Controllers/` — `HomeController` (головна, «Про ОСББ», контакти), `FlatController` (квартири: список, додавання, редагування, видалення; сторінка комунальних служб `Utilities`), `ResidentController` (мешканці: список, додавання, редагування, видалення), `AccountController` і `ManageController` (вхід, реєстрація, профіль — шаблон ASP.NET Identity);
  - `Models/House/` — сутності EF: `Flat` (квартира), `Resident` (мешканець із зовнішнім ключем на квартиру);
  - `ViewModels/` — `FlatViewModel`, `ResidentViewModel` з правилами валідації форм;
  - `Common/HouseContext.cs` — контекст EF з таблицями `Flats` і `Residents`;
  - `Repositorys/` — `IHouseRepository`, `HouseRepository` (доступ до бази);
  - `Services/` — `IHouseService`, `HouseService` (шар між контролерами й репозиторієм);
  - `Views/Flat/` — список квартир, `AddNewFlat` і `EditFlat` зі спільною формою `_FlatForm`, `Utilities`; `Views/Resident/` — `Index`, `Add`, `Edit`, `Delete` і спільні поля `_ResidentFields`; `Views/Shared/_Layout.cshtml` — меню.
- `Database/schema.sql` — довідковий SQL-скрипт схеми бази; самі таблиці створює EF Code First.
- До 05.06.2018 історія містить першу версію проєкту — `OSBB.sln`, `OSBB/`.
- `mikroservises/`, `LightweightApi.sln` (03–17.05.2018) — приклади ASP.NET Core Web API з [filipw/aspnetcore-api-samples](https://github.com/filipw/aspnetcore-api-samples) (MIT License, Copyright (c) 2019 Filip W), які планувалося додати до проєкту; прибрано 17.05.2018 через брак часу.
- Гілка `0406` — коміт 04.06.2018, що не увійшов в основну гілку.

## Запуск

Visual Studio 2017 або новіша. Сторонні бібліотеки до репозиторію не входять: NuGet-пакети відновлюються за `packages.config`, а скрипти й стилі jQuery, Bootstrap тощо — перевстановленням пакетів (`Update-Package -reinstall`). База — SQL Server LocalDB, рядок підключення в `OSBB-N/Web.config`.

Таблиці створює Entity Framework під час першого запуску (Code First без міграцій). Якщо локальна база лишилася від версії без таблиці `Residents` (до жовтня 2018), EF повідомить, що модель змінилася: базу треба видалити (SQL Server Object Explorer → `(localdb)\MSSQLLocalDB` → база `aspnet-OSBB-N-…` → Delete) разом із файлами в `OSBB-N/App_Data`, і EF створить її заново. Облікові записи й квартири при цьому видаляються.

## Історія

Проєкт травень–червень 2018. Коміти перенесено з оригінального git-репозиторію: дати й порядок справжні, повідомлення переписано описово (оригінальне — у тілі кожного коміту). Останні зміни 12–14.06.2018 не були закомічені, ці три коміти відновлено приблизно — за датами змін файлів. Перед публікацією з історії прибрано збірки, NuGet-пакети, бази даних і сторонні бібліотеки, а імена, телефони й назву ОСББ замінено заглушками. README і .gitignore написано у 2026 році під час публікації й додано в останній коміт. На GitHub викладено у 2026.

Коміти з 18.06.2018 — продовження проєкту після захисту: виправлення, модуль «Мешканці», документація. Їх додано у 2026 році хмарною сесією Claude Code за завданням автора з датами в межах 2018 року.
